PulseGuard Documentation Overview PulseGuard is a Remote Patient Monitoring (RPM) platform developed as part of a fourth-year DevOps project.

The platform monitors patient biometric telemetry, classifies health risks using predefined rules, and presents information through a clinician dashboard.

The project currently consists of:

Synthetic patient telemetry generation FastAPI backend services Alert classification engine React frontend dashboard Risk analysis and patient monitoring

Project Goals The primary goals of PulseGuard are:

Monitor patient health remotely Detect potential deterioration through telemetry analysis Support clinician decision-making Demonstrate modern DevOps practices Showcase Infrastructure as Code, CI/CD and cloud deployment strategies Technology Stack Frontend React Vite JavaScript Backend Python FastAPI Pydantic Simulation Python Requests
